# Tillgänglighet

Svenska Modellens webbplatser ska vara tillgängliga och användbara för så många som möjligt. Målet är att vara förenlig med WCAG 2.2 nivå AA.

Om du upptäcker ett tillgänglighetsproblem får du gärna  med en beskrivning av problemet och vilken sida det gäller.

Eventuella tillgänglighetsproblem går att rapportera antingen:

1. Via mejl till [henry@catalinismith.se](mailto:henry@catalinismith.se) eller
2. Via GitHub issues på [github.com/svenskamodellen/svenskamodellen.github.io/issues/new](https://github.com/svenskamodellen/svenskamodellen.github.io/issues/new)
